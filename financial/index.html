    Financial structures¶

    v0.1.0 is in development

    This page documents loss-side reinsurance mechanics. Premium, ceding commission and reinstatement premium are not yet modelled.

    A Programme applies reinsurance structures to a simulated YELT and returns gross, ceded and net loss on every occurrence.

    import catagg as ca

elt = ca.swiss_multiperil_elt(n_events=1_000, seed=0)
yelt = ca.simulate(elt, n_years=100_000, secondary_uncertainty=True, seed=42)

programme = ca.Programme([
    ca.QuotaShare(cession=0.20),
    ca.ExcessOfLoss(attachment=50e6, limit=50e6, reinstatements=2),
    ca.AggregateStopLoss(attachment=100e6, limit=100e6),
])
result = programme.apply(yelt)

gross = ca.ep_curve(result.yelt, kind="OEP")
net = ca.ep_curve(result.yelt, kind="OEP", column="net_loss")

    result.yelt holds gross_loss, ceded_loss and net_loss side by side, and result.ceded_by_structure holds each structure's own cession, labelled by position: 1_quota_share, 2_excess_of_loss, 3_aggregate_stop_loss.

    Programme order is inuring order¶

    Each structure protects what the structures before it left retained. In the programme above the quota share takes 20% of every gross loss; the 50m xs 50m layer then responds to the retained 80%, not to the gross; and the stop-loss responds to what the layer left. Reversing two structures changes the answer, so the order in the list is the order of application.

    Structures¶

    Structure Pays, per occurrence Running total
    QuotaShare(cession) cession × retained None
    ExcessOfLoss(attachment, limit, reinstatements) Retained loss above attachment, up to limit Annual cap limit × (1 + reinstatements), or none if reinstatements=None
    AggregateStopLoss(attachment, limit) Its share of the annual recovery above attachment Annual deductible, then annual limit

    reinstatements has no default. Market terms vary too much for any default to be safe, and a silently assumed one would change every net figure.

    AggregateStopLoss takes its attachment and limit in money, which also makes it an aggregate excess of loss. A stop-loss quoted as a loss ratio converts to this form given the subject premium.

    Order within the year¶

    The per-occurrence layer's annual cap and the stop-loss's deductible and limit are consumed in chronological order, using occurrence_index (see Simulation). A 50 xs 50 layer with two reinstatements pays at most 150 a year. Given layer losses of 30, 50, 50 and 40 in that order, the fourth recovers only the 20 left. In the reverse order it is the 30 that is cut, to 10.

    Order never changes a structure's annual total, so AAL and AEP of ceded and net loss are unaffected by it. It does change which occurrence is cut off, and so the net loss per occurrence and the net OEP. Allocating the stop-loss recovery the same way is what gives a net OEP after an aggregate cover a definite meaning.

    Conservation, in floating point¶

    Net loss is what remains after each structure's cession is taken off in turn, and ceded_loss is computed once, as gross_loss − net_loss. With that construction net_loss + ceded_loss equals gross_loss to within one unit in the last place on every occurrence: rounding one subtraction moves the result by at most half a unit, and adding back at most doubles it.

    That is the strongest form the identity can take in floating point. A bitwise equality is not attainable: for a 20% quota share alone, a few percent of occurrences differ from gross by one unit in the last place, whatever order the arithmetic is done in.

    Programme.apply also checks every structure's cession, including structures written outside the library against the Structure protocol: none may be negative, and none may exceed the loss it was offered. So net loss can never go negative.

    API¶

    catagg.financial.structures ¶

    Reinsurance structures.

    Each structure is told what the cedant still retains on every occurrence, after the structures ahead of it in the programme, and returns how much of that it takes. Every cession is non-negative and never exceeds the retained loss it was offered; Programme.apply checks this for every structure, including ones written outside this module against the Structure protocol.

    Only loss is modelled. Premium, ceding commission and reinstatement premium are cash flows beside the loss and do not enter net + ceded = gross.

    """Cede a fixed share of every occurrence.

    Parameters
    ----------

    Examples
    --------

        return ceded

    @dataclass(frozen=True, kw_only=True)
class ExcessOfLoss:
    """Per-occurrence excess of loss, with a limited number of reinstatements.

    On each occurrence the layer pays the retained loss above ``attachment``,
    up to ``limit``. Every payment uses up cover, which is reinstated up to
    ``reinstatements`` times, so the most the layer pays in a year is
    ``limit * (1 + reinstatements)``. Cover is consumed in chronological order:
    once the year's cover is gone, later occurrences recover nothing.

    Parameters
    ----------
    attachment
        Retention per occurrence.
    limit
        Most the layer pays on one occurrence.
    reinstatements
        Number of times the limit is reinstated in a year, or ``None`` for
        unlimited reinstatement. Required: market terms vary too widely for any
        default to be safe.

    Notes
    -----
    The order of occurrences changes which one is cut off when the annual cap
    binds, and so the net loss per occurrence and the net OEP. It never changes
    the layer's annual total, which is
    ``min(sum of per-occurrence layer losses, limit * (1 + reinstatements))``.

    Reinstatement premium is not modelled in this version.

    Examples
    --------
    A 50 xs 50 layer with two reinstatements pays at most 150 a year. Of four
    layer losses of 30, 50, 50 and 40, the last recovers only the 20 left:

    >>> import numpy as np
    >>> layer = ExcessOfLoss(attachment=50.0, limit=50.0, reinstatements=2)
    >>> layer.cede(np.array([80.0, 120.0, 200.0, 90.0]), np.zeros(4, dtype=np.int64)).tolist()
    [30.0, 50.0, 50.0, 20.0]
    """

    attachment: float
    limit: float
    reinstatements: int | None
    label: ClassVar[str] = "excess_of_loss"

    def __post_init__(self) -> None:
        _require_finite_non_negative("attachment", self.attachment)
        _require_positive("limit", self.limit)
        if self.reinstatements is not None and not (
            isinstance(self.reinstatements, int)
            and not isinstance(self.reinstatements, bool)
            and self.reinstatements >= 0
        ):
            raise CataggError(
                "reinstatements must be a non-negative integer or None, "
                f"got {self.reinstatements!r}."
            )

    @property
    def annual_limit(self) -> float:
        """Most the layer can pay in one year, ``limit * (1 + reinstatements)``."""
        if self.reinstatements is None:
            return math.inf
        return self.limit * (1 + self.reinstatements)

    def cede(self, retained: NDArray[np.float64], years: NDArray[np.int64]) -> NDArray[np.float64]:
        """Cede the layer loss on each occurrence, until the year's cover runs out.

        Parameters
        ----------
        retained
            Loss still retained on each occurrence before this structure.
        years
            Simulated year of each occurrence, sorted, chronological within year.

        Returns
        -------
        numpy.ndarray
            Amount ceded on each occurrence.
        """
        layer_loss = np.clip(retained - self.attachment, 0.0, self.limit)
        return cap_within_years(layer_loss, years, self.annual_limit)

class AggregateStopLoss:
    """Aggregate cover on each year's retained loss.

    The cover pays the part of the year's retained loss above ``attachment``,
    up to ``limit``. Attachment and limit are amounts of money, so this is also
    an aggregate excess of loss; a stop-loss quoted as a loss ratio converts to
    one given the subject premium.

    The annual recovery is allocated to occurrences in chronological order: the
    cover attaches part-way through the occurrence that takes the running total
    past ``attachment``, and stops paying on the one that exhausts ``limit``.
    That allocation is what makes a net OEP after an aggregate cover
    well-defined.

    Parameters
    ----------
    attachment
        Annual aggregate retention.
    limit
        Most the cover pays in a year; may be ``inf``.

    Examples
    --------
    Retained losses of 60, 70 and 90 build to 220. A 100 xs 100 cover attaches
    30 into the second occurrence and is exhausted within the third:

    >>> import numpy as np
    >>> cover = AggregateStopLoss(attachment=100.0, limit=100.0)
    >>> cover.cede(np.array([60.0, 70.0, 90.0]), np.zeros(3, dtype=np.int64)).tolist()
    [0.0, 30.0, 70.0]
    """

    attachment: float
    limit: float
    label: ClassVar[str] = "aggregate_stop_loss"

    def __post_init__(self) -> None:
        _require_finite_non_negative("attachment", self.attachment)
        _require_positive("limit", self.limit)

    def cede(self, retained: NDArray[np.float64], years: NDArray[np.int64]) -> NDArray[np.float64]:
        """Cede each occurrence's share of the year's aggregate recovery.

        Parameters
        ----------
        retained
            Loss still retained on each occurrence before this structure.
        years
            Simulated year of each occurrence, sorted, chronological within year.

        Returns
        -------
        numpy.ndarray
            Amount ceded on each occurrence.
        """
        deductible_left = np.maximum(self.attachment - cumulative_before(retained, years), 0.0)
        above_attachment = np.maximum(retained - deductible_left, 0.0)
        return cap_within_years(above_attachment, years, self.limit)

    Programme ¶

    Reinsurance structures applied in order.

    Each structure protects what the structures before it left retained, so a quota share listed first cedes a share of the gross loss and an excess of loss listed after it sees only the retained share. Order therefore matters, and it is the order given here.

    class Programme:
    """Reinsurance structures applied in order.

    Each structure protects what the structures before it left retained, so a
    quota share listed first cedes a share of the gross loss and an excess of
    loss listed after it sees only the retained share. Order therefore matters,
    and it is the order given here.

    Parameters
    ----------
    structures
        The structures, in the order they apply. Any object satisfying the
        `Structure` protocol is accepted.

    Examples
    --------
    >>> import catagg as ca
    >>> elt = ca.swiss_multiperil_elt(n_events=200, seed=0)
    >>> yelt = ca.simulate(elt, n_years=1_000, seed=1)
    >>> programme = ca.Programme(
    ...     [
    ...         ca.QuotaShare(cession=0.2),
    ...         ca.ExcessOfLoss(attachment=50e6, limit=50e6, reinstatements=2),
    ...         ca.AggregateStopLoss(attachment=100e6, limit=100e6),
    ...     ]
    ... )
    >>> result = programme.apply(yelt)
    >>> list(result.yelt.columns[-2:])
    ['ceded_loss', 'net_loss']
    >>> net = ca.ep_curve(result.yelt, kind="OEP", column="net_loss")
    >>> net.n_years
    1000
    """

    def __init__(self, structures: Sequence[Structure]) -> None:
        for structure in structures:
            if not isinstance(structure, Structure):
                raise CataggError(
                    f"{structure!r} is not a reinsurance structure: it needs a "
                    "label and a cede(retained, years) method."
                )
        self._structures = tuple(structures)

    @property
    def structures(self) -> tuple[Structure, ...]:
        """The structures, in the order they apply."""
        return self._structures

    def __repr__(self) -> str:
        return f"Programme({list(self._structures)!r})"

    def apply(self, yelt: pd.DataFrame) -> ProgrammeResult:
        """Apply the programme to every simulated occurrence.

        Parameters
        ----------
        yelt
            Year event loss table, as returned by `catagg.simulate`. Rows are
            put in order of ``(sim_year, occurrence_index)`` before anything is
            ceded; the order they arrive in is not relied on.

        Returns
        -------
        ProgrammeResult
            Gross, ceded and net loss per occurrence, and each structure's
            cession.

        Raises
        ------
        CataggError
            If a required column is missing, two rows share a ``sim_year`` and
            ``occurrence_index``, the year count is unknown, or a structure
            cedes a negative amount or more than it was offered.
        """
        missing = [column for column in _REQUIRED_COLUMNS if column not in yelt.columns]
        if missing:
            raise CataggError(f"the YELT is missing required columns: {missing}.")
        n_years = n_years_of(yelt)

        ordered = yelt.loc[:, list(_REQUIRED_COLUMNS)].sort_values(
            ["sim_year", "occurrence_index"], kind="stable", ignore_index=True
        )
        years = ordered["sim_year"].to_numpy(dtype=np.int64)
        index = ordered["occurrence_index"].to_numpy(dtype=np.int64)
        if years.shape[0] > 1 and np.any((years[1:] == years[:-1]) & (index[1:] == index[:-1])):
            raise CataggError(
                "two occurrences share a sim_year and occurrence_index, so their "
                "order within the year is undefined."
            )

        gross = ordered["gross_loss"].to_numpy(dtype=np.float64)
        retained = gross.copy()
        ceded_columns: dict[str, np.ndarray] = {}
        for position, structure in enumerate(self._structures, start=1):
            ceded = np.asarray(structure.cede(retained, years), dtype=np.float64)
            if ceded.shape != retained.shape or np.any(ceded < 0.0) or np.any(ceded > retained):
                raise CataggError(
                    f"structure {position} ({structure.label}) ceded a negative "
                    "amount, or more than the loss it was offered."
                )
            ceded_columns[f"{position}_{structure.label}"] = ceded
            retained = retained - ceded

        # One subtraction, so net + ceded recovers gross to within one unit in
        # the last place on every occurrence - the float form of an identity.
        result = ordered.assign(ceded_loss=gross - retained, net_loss=retained)
        result = result.loc[:, list(_RESULT_COLUMNS)]
        result.attrs["n_years"] = n_years
        by_structure = pd.DataFrame(ceded_columns, index=result.index)
        return ProgrammeResult(yelt=result, ceded_by_structure=by_structure)
