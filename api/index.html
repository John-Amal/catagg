    AggregateStopLoss dataclass ¶

    Aggregate cover on each year's retained loss.

    The cover pays the part of the year's retained loss above attachment, up to limit. Attachment and limit are amounts of money, so this is also an aggregate excess of loss; a stop-loss quoted as a loss ratio converts to one given the subject premium.

    The annual recovery is allocated to occurrences in chronological order: the cover attaches part-way through the occurrence that takes the running total past attachment, and stops paying on the one that exhausts limit. That allocation is what makes a net OEP after an aggregate cover well-defined.

    Parameters:

    Name Type Description Default
    attachment float

    Annual aggregate retention.

    		 required
    limit float

    Most the cover pays in a year; may be inf.

    		 required

    Examples:

    Retained losses of 60, 70 and 90 build to 220. A 100 xs 100 cover attaches 30 into the second occurrence and is exhausted within the third:

    >>> import numpy as np
>>> cover = AggregateStopLoss(attachment=100.0, limit=100.0)
>>> cover.cede(np.array([60.0, 70.0, 90.0]), np.zeros(3, dtype=np.int64)).tolist()
[0.0, 30.0, 70.0]

    Per-occurrence excess of loss, with a limited number of reinstatements.

    On each occurrence the layer pays the retained loss above attachment, up to limit. Every payment uses up cover, which is reinstated up to reinstatements times, so the most the layer pays in a year is limit * (1 + reinstatements). Cover is consumed in chronological order: once the year's cover is gone, later occurrences recover nothing.

    Parameters:

    Name Type Description Default
    attachment float

    Retention per occurrence.

    		 required
    limit float

    Most the layer pays on one occurrence.

    		 required
    reinstatements int | None

    Number of times the limit is reinstated in a year, or None for unlimited reinstatement. Required: market terms vary too widely for any default to be safe.

    		 required
    Notes

    The order of occurrences changes which one is cut off when the annual cap binds, and so the net loss per occurrence and the net OEP. It never changes the layer's annual total, which is min(sum of per-occurrence layer losses, limit * (1 + reinstatements)).

    """Per-occurrence excess of loss, with a limited number of reinstatements.

    On each occurrence the layer pays the retained loss above ``attachment``,
    up to ``limit``. Every payment uses up cover, which is reinstated up to
    ``reinstatements`` times, so the most the layer pays in a year is
    ``limit * (1 + reinstatements)``. Cover is consumed in chronological order:
    once the year's cover is gone, later occurrences recover nothing.

    Parameters
    ----------
    attachment
        Retention per occurrence.
    limit
        Most the layer pays on one occurrence.
    reinstatements
        Number of times the limit is reinstated in a year, or ``None`` for
        unlimited reinstatement. Required: market terms vary too widely for any
        default to be safe.

    Notes
    -----
    The order of occurrences changes which one is cut off when the annual cap
    binds, and so the net loss per occurrence and the net OEP. It never changes
    the layer's annual total, which is
    ``min(sum of per-occurrence layer losses, limit * (1 + reinstatements))``.

    Reinstatement premium is not modelled in this version.

    Examples
    --------
    A 50 xs 50 layer with two reinstatements pays at most 150 a year. Of four
    layer losses of 30, 50, 50 and 40, the last recovers only the 20 left:

    >>> import numpy as np
    >>> layer = ExcessOfLoss(attachment=50.0, limit=50.0, reinstatements=2)
    >>> layer.cede(np.array([80.0, 120.0, 200.0, 90.0]), np.zeros(4, dtype=np.int64)).tolist()
    [30.0, 50.0, 50.0, 20.0]
    """

    attachment: float
    limit: float
    reinstatements: int | None
    label: ClassVar[str] = "excess_of_loss"

    def __post_init__(self) -> None:
        _require_finite_non_negative("attachment", self.attachment)
        _require_positive("limit", self.limit)
        if self.reinstatements is not None and not (
            isinstance(self.reinstatements, int)
            and not isinstance(self.reinstatements, bool)
            and self.reinstatements >= 0
        ):
            raise CataggError(
                "reinstatements must be a non-negative integer or None, "
                f"got {self.reinstatements!r}."
            )

    @property
    def annual_limit(self) -> float:
        """Most the layer can pay in one year, ``limit * (1 + reinstatements)``."""
        if self.reinstatements is None:
            return math.inf
        return self.limit * (1 + self.reinstatements)

    def cede(self, retained: NDArray[np.float64], years: NDArray[np.int64]) -> NDArray[np.float64]:
        """Cede the layer loss on each occurrence, until the year's cover runs out.

        Parameters
        ----------
        retained
            Loss still retained on each occurrence before this structure.
        years
            Simulated year of each occurrence, sorted, chronological within year.

        Returns
        -------
        numpy.ndarray
            Amount ceded on each occurrence.
        """
        layer_loss = np.clip(retained - self.attachment, 0.0, self.limit)
        return cap_within_years(layer_loss, years, self.annual_limit)

    class Programme:
    """Reinsurance structures applied in order.

    Each structure protects what the structures before it left retained, so a
    quota share listed first cedes a share of the gross loss and an excess of
    loss listed after it sees only the retained share. Order therefore matters,
    and it is the order given here.

    Parameters
    ----------
    structures
        The structures, in the order they apply. Any object satisfying the
        `Structure` protocol is accepted.

    Examples
    --------
    >>> import catagg as ca
    >>> elt = ca.swiss_multiperil_elt(n_events=200, seed=0)
    >>> yelt = ca.simulate(elt, n_years=1_000, seed=1)
    >>> programme = ca.Programme(
    ...     [
    ...         ca.QuotaShare(cession=0.2),
    ...         ca.ExcessOfLoss(attachment=50e6, limit=50e6, reinstatements=2),
    ...         ca.AggregateStopLoss(attachment=100e6, limit=100e6),
    ...     ]
    ... )
    >>> result = programme.apply(yelt)
    >>> list(result.yelt.columns[-2:])
    ['ceded_loss', 'net_loss']
    >>> net = ca.ep_curve(result.yelt, kind="OEP", column="net_loss")
    >>> net.n_years
    1000
    """

    def __init__(self, structures: Sequence[Structure]) -> None:
        for structure in structures:
            if not isinstance(structure, Structure):
                raise CataggError(
                    f"{structure!r} is not a reinsurance structure: it needs a "
                    "label and a cede(retained, years) method."
                )
        self._structures = tuple(structures)

    @property
    def structures(self) -> tuple[Structure, ...]:
        """The structures, in the order they apply."""
        return self._structures

    def __repr__(self) -> str:
        return f"Programme({list(self._structures)!r})"

    def apply(self, yelt: pd.DataFrame) -> ProgrammeResult:
        """Apply the programme to every simulated occurrence.

        Parameters
        ----------
        yelt
            Year event loss table, as returned by `catagg.simulate`. Rows are
            put in order of ``(sim_year, occurrence_index)`` before anything is
            ceded; the order they arrive in is not relied on.

        Returns
        -------
        ProgrammeResult
            Gross, ceded and net loss per occurrence, and each structure's
            cession.

        Raises
        ------
        CataggError
            If a required column is missing, two rows share a ``sim_year`` and
            ``occurrence_index``, the year count is unknown, or a structure
            cedes a negative amount or more than it was offered.
        """
        missing = [column for column in _REQUIRED_COLUMNS if column not in yelt.columns]
        if missing:
            raise CataggError(f"the YELT is missing required columns: {missing}.")
        n_years = n_years_of(yelt)

        ordered = yelt.loc[:, list(_REQUIRED_COLUMNS)].sort_values(
            ["sim_year", "occurrence_index"], kind="stable", ignore_index=True
        )
        years = ordered["sim_year"].to_numpy(dtype=np.int64)
        index = ordered["occurrence_index"].to_numpy(dtype=np.int64)
        if years.shape[0] > 1 and np.any((years[1:] == years[:-1]) & (index[1:] == index[:-1])):
            raise CataggError(
                "two occurrences share a sim_year and occurrence_index, so their "
                "order within the year is undefined."
            )

        gross = ordered["gross_loss"].to_numpy(dtype=np.float64)
        retained = gross.copy()
        ceded_columns: dict[str, np.ndarray] = {}
        for position, structure in enumerate(self._structures, start=1):
            ceded = np.asarray(structure.cede(retained, years), dtype=np.float64)
            if ceded.shape != retained.shape or np.any(ceded < 0.0) or np.any(ceded > retained):
                raise CataggError(
                    f"structure {position} ({structure.label}) ceded a negative "
                    "amount, or more than the loss it was offered."
                )
            ceded_columns[f"{position}_{structure.label}"] = ceded
            retained = retained - ceded

        # One subtraction, so net + ceded recovers gross to within one unit in
        # the last place on every occurrence - the float form of an identity.
        result = ordered.assign(ceded_loss=gross - retained, net_loss=retained)
        result = result.loc[:, list(_RESULT_COLUMNS)]
        result.attrs["n_years"] = n_years
        by_structure = pd.DataFrame(ceded_columns, index=result.index)
        return ProgrammeResult(yelt=result, ceded_by_structure=by_structure)

            "two occurrences share a sim_year and occurrence_index, so their "
            "order within the year is undefined."
        )

    gross = ordered["gross_loss"].to_numpy(dtype=np.float64)
    retained = gross.copy()
    ceded_columns: dict[str, np.ndarray] = {}
    for position, structure in enumerate(self._structures, start=1):
        ceded = np.asarray(structure.cede(retained, years), dtype=np.float64)
        if ceded.shape != retained.shape or np.any(ceded < 0.0) or np.any(ceded > retained):
            raise CataggError(
                f"structure {position} ({structure.label}) ceded a negative "
                "amount, or more than the loss it was offered."
            )
        ceded_columns[f"{position}_{structure.label}"] = ceded
        retained = retained - ceded

    # One subtraction, so net + ceded recovers gross to within one unit in
    # the last place on every occurrence - the float form of an identity.
    result = ordered.assign(ceded_loss=gross - retained, net_loss=retained)
    result = result.loc[:, list(_RESULT_COLUMNS)]
    result.attrs["n_years"] = n_years
    by_structure = pd.DataFrame(ceded_columns, index=result.index)
    return ProgrammeResult(yelt=result, ceded_by_structure=by_structure)

class NegativeBinomial(FrequencyModel):
    """Negative binomial annual counts, over-dispersed relative to Poisson.

    Parameterised by the shape, or contagion, parameter ``dispersion`` = ``k``,
    so the annual count of a group with total rate ``Lambda`` has mean
    ``Lambda`` and variance ``Lambda + Lambda ** 2 / k``. Small ``k`` means heavy
    clustering; ``k`` to infinity recovers the Poisson.

    To specify a variance-to-mean ratio instead, use
    `NegativeBinomial.from_variance_to_mean_ratio`.

    Attributes
    ----------
    dispersion
        Shape parameter ``k``, strictly positive.
    """

    dispersion: float

    def __post_init__(self) -> None:
        """Reject a non-positive or non-finite dispersion."""
        if not np.isfinite(self.dispersion) or self.dispersion <= 0.0:
            raise ValueError(
                f"NegativeBinomial dispersion must be finite and strictly positive, "
                f"got {self.dispersion!r}."
            )

    @classmethod
    def from_variance_to_mean_ratio(cls, ratio: float, group_rate: float) -> NegativeBinomial:
        """Build the model whose annual count variance is ``ratio`` times its mean.

        The mapping depends on the group rate, because a variance-to-mean ratio
        is not scale-free for the negative binomial: ``k = Lambda / (phi - 1)``.

        Parameters
        ----------
        ratio
            Variance-to-mean ratio ``phi``, strictly greater than one.
        group_rate
            Total annual rate ``Lambda`` of the group.

        Returns
        -------
        NegativeBinomial
            The corresponding model.

        Raises
        ------
        ValueError
            If ``ratio`` is not strictly greater than one.
        """
        if ratio <= 1.0:
            raise ValueError(
                f"variance-to-mean ratio must exceed 1 for a negative binomial, got {ratio!r}; "
                "use Poisson() for a ratio of exactly 1."
            )
        return cls(dispersion=group_rate / (ratio - 1.0))

    @property
    def excess_variance_coefficient(self) -> float:
        """Return the reciprocal of the dispersion."""
        return 1.0 / self.dispersion

    def sample_annual_counts(
        self, group_rate: float, n_years: int, rng: Generator
    ) -> NDArray[np.int64]:
        """Draw negative binomial counts with mean ``group_rate``.

        Parameters
        ----------
        group_rate
            Total annual rate of the group.
        n_years
            Number of years to draw.
        rng
            Source of randomness.

        Returns
        -------
        numpy.ndarray
            Shape ``(n_years,)``, non-negative integer counts.
        """
        success_probability = self.dispersion / (self.dispersion + group_rate)
        return rng.negative_binomial(n=self.dispersion, p=success_probability, size=n_years).astype(
            np.int64, copy=False
        )

    @dataclass(frozen=True, eq=False)
class EPCurve:
    """An exceedance probability curve, held as the full simulated distribution.

    Build one with `ep_curve`. The whole per-year loss vector is kept rather
    than a summarised curve, so any return period, tail metric or standard
    error can be read afterwards without re-simulating.

    Attributes
    ----------
    losses
        Per-year loss, sorted ascending, one entry per simulated year including
        years with no events.
    kind
        ``"OEP"`` or ``"AEP"``.
    """

    losses: NDArray[np.float64]
    kind: EPKind

    def __len__(self) -> int:
        """Return the number of simulated years."""
        return int(self.losses.shape[0])

    @property
    def n_years(self) -> int:
        """Number of simulated years behind the curve."""
        return len(self)

    @property
    def mean(self) -> float:
        """Mean per-year loss. For an AEP curve this is the AAL."""
        return float(self.losses.mean())

    @property
    def mean_standard_error(self) -> float:
        """Monte Carlo standard error of `mean`.

        An ordinary standard error of a mean. `catagg.aal_standard_error`
        computes the same quantity in closed form from the ELT, without
        simulating; agreement between the two is a check on both.
        """
        return float(self.losses.std(ddof=1) / np.sqrt(self.n_years))

    def _check_return_periods(self, values: NDArray[np.float64]) -> None:
        """Reject return periods the simulation cannot support.

        Raises
        ------
        CataggError
            If any return period is at or below one, or longer than the
            simulation itself. The upper bound is deliberate: reading a
            10,000-year loss off 10,000 simulated years returns the single
            largest year and dresses one observation up as a return period.
        """
        if np.any(values <= 1.0):
            raise CataggError("return_period must be greater than 1.")
        if np.any(values > self.n_years):
            longest = float(values.max())
            raise CataggError(
                f"return_period {longest:g} exceeds the {self.n_years} simulated years. "
                f"Estimating it needs at least {int(np.ceil(longest))} years; beyond that "
                "the estimate is the largest simulated year, not a return period."
            )

    def _quantile(self, probability: NDArray[np.float64]) -> NDArray[np.float64]:
        """Empirical quantile at the Weibull plotting position."""
        clipped = np.clip(probability, 0.0, 1.0)
        return np.asarray(np.quantile(self.losses, clipped, method="weibull"), dtype=np.float64)

    def at_return_period(
        self, return_period: ReturnPeriods = STANDARD_RETURN_PERIODS
    ) -> pd.DataFrame:
        """Return the loss at one or more return periods, with its standard error.

        Parameters
        ----------
        return_period
            Return period in years, scalar or sequence. Defaults to
            `STANDARD_RETURN_PERIODS`.

        Returns
        -------
        pandas.DataFrame
            Columns ``return_period``, ``exceedance_probability``, ``loss`` and
            ``se``, one row per requested return period.

        Raises
        ------
        CataggError
            If a return period is at or below one, or exceeds the number of
            simulated years.

        Examples
        --------
        >>> import catagg as ca
        >>> elt = ca.swiss_multiperil_elt(n_events=200, seed=0)
        >>> yelt = ca.simulate(elt, n_years=20_000, seed=1)
        >>> curve = ca.ep_curve(yelt, kind="AEP")
        >>> list(curve.at_return_period([100, 200]).columns)
        ['return_period', 'exceedance_probability', 'loss', 'se']
        """
        values = _as_return_periods(return_period)
        self._check_return_periods(values)

        probability = 1.0 / values
        level = 1.0 - probability
        bandwidth = np.sqrt(probability * (1.0 - probability) / self.n_years)
        spread = self._quantile(level + bandwidth) - self._quantile(level - bandwidth)

        return pd.DataFrame(
            {
                "return_period": values,
                "exceedance_probability": probability,
                "loss": self._quantile(level),
                "se": spread / 2.0,
            }
        )

    def tvar(self, return_period: ReturnPeriods = STANDARD_RETURN_PERIODS) -> pd.DataFrame:
        """Return the tail value at risk at one or more return periods.

        TVaR is the mean loss in the years that exceed the return period, so it
        answers what capital regimes actually ask: not "how bad is the 1-in-200
        year" but "how bad is the average year worse than that". It is computed
        as the integrated expected shortfall over the largest ``n / R`` years,
        with a fractional weight on the boundary year so the figure stays
        continuous in the return period.

        Parameters
        ----------
        return_period
            Return period in years, scalar or sequence. Defaults to
            `STANDARD_RETURN_PERIODS`.

        Returns
        -------
        pandas.DataFrame
            Columns ``return_period``, ``exceedance_probability``, ``tvar`` and
            ``se``. The standard error is ``NaN`` where fewer than two
            simulated years exceed the return period.

        Raises
        ------
        CataggError
            If a return period is at or below one, or exceeds the number of
            simulated years.
        """
        values = _as_return_periods(return_period)
        self._check_return_periods(values)

        probability = 1.0 / values
        descending = self.losses[::-1]
        var = self._quantile(1.0 - probability)

        exceeding = probability * self.n_years
        whole = np.floor(exceeding).astype(np.int64)
        cumulative = np.concatenate(([0.0], np.cumsum(descending)))

        # The whole years above the threshold, plus the fraction of the next one
        # that the return period reaches into.
        boundary = descending[np.minimum(whole, self.n_years - 1)]
        total = cumulative[whole] + (exceeding - whole) * boundary
        tail_mean = total / exceeding

        standard_error = np.full(values.shape, np.nan, dtype=np.float64)
        for index, count in enumerate(whole):
            if count < 2:
                continue
            tail = descending[:count]
            tail_variance = float(tail.var(ddof=1))
            threshold_term = (1.0 - probability[index]) * (tail_mean[index] - var[index]) ** 2
            standard_error[index] = np.sqrt((tail_variance + threshold_term) / exceeding[index])

        return pd.DataFrame(
            {
                "return_period": values,
                "exceedance_probability": probability,
                "tvar": tail_mean,
                "se": standard_error,
            }
        )

    def to_frame(self) -> pd.DataFrame:
        """Return the whole curve, one row per simulated year.

        Returns
        -------
        pandas.DataFrame
            Columns ``rank`` (1 for the largest year), ``exceedance_probability``
            at the Weibull plotting position, ``return_period`` and ``loss``,
            ordered from the largest loss down.
        """
        rank = np.arange(1, self.n_years + 1, dtype=np.int64)
        probability = rank / (self.n_years + 1)
        return pd.DataFrame(
            {
                "rank": rank,
                "exceedance_probability": probability,
                "return_period": 1.0 / probability,
                "loss": self.losses[::-1],
            }
        )

class BetaSeverity:
    """A method-of-moments severity fit, one distribution per ELT row.

    Build one with `BetaSeverity.from_elt`. Every array is indexed by row
    position in the validated ELT, which is what `catagg.simulate` carries
    through the year loop.

    Attributes
    ----------
    mean_loss
        Target mean loss per event, in loss units.
    exposure_value
        Upper end of the support per event, in loss units.
    alpha
        Beta shape parameter ``alpha``. Zero outside `SeverityRegime.BETA`.
    beta
        Beta shape parameter ``beta``. Zero outside `SeverityRegime.BETA`.
    regime
        `SeverityRegime` code per event, as ``int8``.
    """

    mean_loss: NDArray[np.float64]
    exposure_value: NDArray[np.float64]
    alpha: NDArray[np.float64]
    beta: NDArray[np.float64]
    regime: NDArray[np.int8]

    def __len__(self) -> int:
        """Return the number of fitted events."""
        return int(self.mean_loss.shape[0])

    @classmethod
    def from_elt(cls, elt: pd.DataFrame) -> BetaSeverity:
        """Fit the severity model to every row of an event loss table.

        The ELT is validated first, so the feasibility bound holds and ``nu``
        cannot be meaningfully negative. `catagg.validate_elt` allows a
        relative slack of ``1e-9`` on that bound, so a row written by another
        tool in lower precision can arrive a hair above it; such a row is
        assigned to `SeverityRegime.TWO_POINT`, which reproduces its mean
        exactly and its variance to within that same relative slack.

        Parameters
        ----------
        elt
            Event loss table.

        Returns
        -------
        BetaSeverity
            The fit, with one entry per ELT row in ELT row order.

        Examples
        --------
        >>> import numpy as np
        >>> import catagg as ca
        >>> from catagg.severity import BetaSeverity
        >>> elt = ca.swiss_multiperil_elt(n_events=100, seed=0)
        >>> fit = BetaSeverity.from_elt(elt)
        >>> bool(np.allclose(fit.mean, elt["mean_loss"]))
        True
        """
        elt = validate_elt(elt)
        mean_loss = elt["mean_loss"].to_numpy(dtype=np.float64)
        std_loss = elt["std_loss"].to_numpy(dtype=np.float64)
        exposure_value = elt["exposure_value"].to_numpy(dtype=np.float64)

        n_events = mean_loss.shape[0]
        alpha = np.zeros(n_events, dtype=np.float64)
        beta = np.zeros(n_events, dtype=np.float64)
        regime = np.full(n_events, SeverityRegime.DEGENERATE, dtype=np.int8)

        # nu is only defined where the variance is positive; everything else is
        # a spike at the mean and needs no shape parameters.
        stochastic = std_loss > 0.0
        positions = np.flatnonzero(stochastic)
        scaled_mean = mean_loss[stochastic] / exposure_value[stochastic]
        scaled_std = std_loss[stochastic] / exposure_value[stochastic]
        with np.errstate(divide="ignore", over="ignore", invalid="ignore"):
            nu = scaled_mean * (1.0 - scaled_mean) / scaled_std**2 - 1.0

        candidate_alpha = scaled_mean * nu
        candidate_beta = (1.0 - scaled_mean) * nu

        # Three outcomes. Two guards decide between them, and neither is
        # cosmetic.
        #
        # The concentration is compared against the validator's slack rather
        # than against zero. A row sitting exactly on the feasibility bound
        # computes nu as a few multiples of machine epsilon, of either sign, so
        # a test against zero would label identical rows differently on the last
        # bit - and a fit labelled BETA reports no endpoint mass for a
        # distribution that in practice produces nothing else. Snapping costs at
        # most `_BOUND_RTOL` of relative variance, which is precisely the
        # precision `validate_elt` has already declared it does not resolve.
        #
        # Non-finite shapes mean the scaled variance underflowed: std_loss is
        # positive but so small relative to exposure_value that float64 cannot
        # tell the distribution from a spike. That is a degenerate fit, not a
        # two-point one - routing it to the endpoints would replace a variance
        # of nearly zero with the largest variance the support allows.
        finite = np.isfinite(candidate_alpha) & np.isfinite(candidate_beta)
        interior = finite & (nu > _BOUND_RTOL) & (candidate_alpha > 0.0) & (candidate_beta > 0.0)
        endpoints = finite & ~interior

        alpha[positions[interior]] = candidate_alpha[interior]
        beta[positions[interior]] = candidate_beta[interior]
        regime[positions[interior]] = SeverityRegime.BETA
        regime[positions[endpoints]] = SeverityRegime.TWO_POINT

        return cls(
            mean_loss=mean_loss,
            exposure_value=exposure_value,
            alpha=alpha,
            beta=beta,
            regime=regime,
        )

    def raw_moment(self, order: int) -> NDArray[np.float64]:
        """Return the analytic raw moment ``E[X ** order]`` of each fit.

        Closed form, with no simulation involved. Orders one and two are what
        the fit was built to reproduce; higher orders are what calibrates the
        tolerance of a sampling test, in the same way
        `catagg.aal_standard_error` calibrates the AAL convergence test.

        For the beta regime the ``k``-th raw moment of ``X / E`` is the product
        of ``(alpha + r) / (alpha + beta + r)`` over ``r`` in ``0 .. k - 1``.
        For the two-point regime it is ``m``, for every order, because ``X`` is
        either ``0`` or ``E`` — which is also the limit of the beta product as
        the concentration goes to zero.

        Parameters
        ----------
        order
            Moment order, a strictly positive integer.

        Returns
        -------
        numpy.ndarray
            ``E[X ** order]`` per event, in loss units raised to ``order``.

        Raises
        ------
        ValueError
            If ``order`` is not a strictly positive integer.
        """
        if not isinstance(order, int) or order <= 0:
            raise ValueError(f"order must be a strictly positive integer, got {order!r}.")

        moment = self.mean_loss**order

        two_point = self.regime == SeverityRegime.TWO_POINT

def from_elt(cls, elt: pd.DataFrame) -> BetaSeverity:
    """Fit the severity model to every row of an event loss table.

    The ELT is validated first, so the feasibility bound holds and ``nu``
    cannot be meaningfully negative. `catagg.validate_elt` allows a
    relative slack of ``1e-9`` on that bound, so a row written by another
    tool in lower precision can arrive a hair above it; such a row is
    assigned to `SeverityRegime.TWO_POINT`, which reproduces its mean
    exactly and its variance to within that same relative slack.

    Parameters
    ----------
    elt
        Event loss table.

    Returns
    -------
    BetaSeverity
        The fit, with one entry per ELT row in ELT row order.

    Examples
    --------
    >>> import numpy as np
    >>> import catagg as ca
    >>> from catagg.severity import BetaSeverity
    >>> elt = ca.swiss_multiperil_elt(n_events=100, seed=0)
    >>> fit = BetaSeverity.from_elt(elt)
    >>> bool(np.allclose(fit.mean, elt["mean_loss"]))
    True
    """
    elt = validate_elt(elt)
    mean_loss = elt["mean_loss"].to_numpy(dtype=np.float64)
    std_loss = elt["std_loss"].to_numpy(dtype=np.float64)
    exposure_value = elt["exposure_value"].to_numpy(dtype=np.float64)

    n_events = mean_loss.shape[0]
    alpha = np.zeros(n_events, dtype=np.float64)
    beta = np.zeros(n_events, dtype=np.float64)
    regime = np.full(n_events, SeverityRegime.DEGENERATE, dtype=np.int8)

    # nu is only defined where the variance is positive; everything else is
    # a spike at the mean and needs no shape parameters.
    stochastic = std_loss > 0.0
    positions = np.flatnonzero(stochastic)
    scaled_mean = mean_loss[stochastic] / exposure_value[stochastic]
    scaled_std = std_loss[stochastic] / exposure_value[stochastic]
    with np.errstate(divide="ignore", over="ignore", invalid="ignore"):
        nu = scaled_mean * (1.0 - scaled_mean) / scaled_std**2 - 1.0

    candidate_alpha = scaled_mean * nu
    candidate_beta = (1.0 - scaled_mean) * nu

    # Three outcomes. Two guards decide between them, and neither is
    # cosmetic.
    #
    # The concentration is compared against the validator's slack rather
    # than against zero. A row sitting exactly on the feasibility bound
    # computes nu as a few multiples of machine epsilon, of either sign, so
    # a test against zero would label identical rows differently on the last
    # bit - and a fit labelled BETA reports no endpoint mass for a
    # distribution that in practice produces nothing else. Snapping costs at
    # most `_BOUND_RTOL` of relative variance, which is precisely the
    # precision `validate_elt` has already declared it does not resolve.
    #
    # Non-finite shapes mean the scaled variance underflowed: std_loss is
    # positive but so small relative to exposure_value that float64 cannot
    # tell the distribution from a spike. That is a degenerate fit, not a
    # two-point one - routing it to the endpoints would replace a variance
    # of nearly zero with the largest variance the support allows.
    finite = np.isfinite(candidate_alpha) & np.isfinite(candidate_beta)
    interior = finite & (nu > _BOUND_RTOL) & (candidate_alpha > 0.0) & (candidate_beta > 0.0)
    endpoints = finite & ~interior

    alpha[positions[interior]] = candidate_alpha[interior]
    beta[positions[interior]] = candidate_beta[interior]
    regime[positions[interior]] = SeverityRegime.BETA
    regime[positions[endpoints]] = SeverityRegime.TWO_POINT

    return cls(
        mean_loss=mean_loss,
        exposure_value=exposure_value,
        alpha=alpha,
        beta=beta,
        regime=regime,
    )

    def swiss_multiperil_elt(
    n_events: int = 1_000,
    seed: int | None = 0,
    perils: tuple[PerilSpec, ...] = SWISS_PERILS,
) -> pd.DataFrame:
    """Generate a synthetic multi-peril event loss table.

    Event mean losses are lognormal; rates are proportional to a negative power
    of the mean loss and then rescaled so each peril's rates sum exactly to its
    ``annual_rate``, which makes the analytic AAL of the result a clean
    reference value. ``std_loss`` is a fixed multiple of ``mean_loss``, clipped
    to stay strictly inside the bound enforced by `catagg.validate_elt`.

    Parameters
    ----------
    n_events
        Total number of events across all perils.
    seed
        Seed for reproducibility. ``None`` draws from OS entropy.
    perils
        Peril specifications.

    Returns
    -------
    pandas.DataFrame
        A valid ELT with the canonical columns.

    Raises
    ------
    ValueError
        If ``n_events`` is not strictly positive.
    """
    if n_events <= 0:
        raise ValueError(f"n_events must be strictly positive, got {n_events}.")

    rng = np.random.default_rng(seed)
    frames: list[pd.DataFrame] = []
    next_event_id = 1

    for spec in perils:
        size = max(1, round(n_events * spec.share_of_events))
        mean_loss = rng.lognormal(mean=spec.log_mean, sigma=spec.log_sigma, size=size)

        weights = mean_loss**-spec.rate_severity_exponent
        rate = spec.annual_rate * weights / weights.sum()

        exposure_value = mean_loss * spec.exposure_multiple
        max_std = np.sqrt(mean_loss * (exposure_value - mean_loss))
        std_loss = np.minimum(spec.coefficient_of_variation * mean_loss, _VARIANCE_SAFETY * max_std)

        frames.append(
            pd.DataFrame(
                {
                    "event_id": np.arange(next_event_id, next_event_id + size, dtype=np.int64),
                    "rate": rate,
                    "mean_loss": mean_loss,
                    "std_loss": std_loss,
                    "exposure_value": exposure_value,
                    "peril": spec.name,
                    "region": rng.choice(np.array(_REGIONS), size=size),
                }
            )
        )
        next_event_id += size

    from catagg.io.elt import validate_elt

    return validate_elt(pd.concat(frames, ignore_index=True))

    def validate_elt(elt: pd.DataFrame) -> pd.DataFrame:
    """Validate an event loss table and return a normalised copy.

    Normalisation means canonical columns coerced to ``ELT_DTYPES`` and moved to
    the front in schema order, any extra columns preserved after them, and the
    index reset.

    The checks are: all canonical columns present; ``event_id`` integral,
    non-null and unique; ``rate`` finite and strictly positive; ``mean_loss`` and
    ``std_loss`` finite and non-negative; ``exposure_value`` finite and strictly
    positive; ``mean_loss`` at most ``exposure_value``; the variance bound below;

    distribution supported on ``[0, exposure_value]`` with mean ``mean_loss``,
    the variance is maximised by the two-point distribution placing all its mass
    at the endpoints, giving ``mean_loss * (exposure_value - mean_loss)``. A row
    exceeding that describes a distribution which cannot exist, so no severity
    model can honour it. Catching it here rather than inside the sampler is what
    stops the secondary uncertainty module from silently clipping the moments it
    was asked to reproduce.

    Parameters
    ----------
    elt
        Candidate event loss table.

    Returns
    -------
    pandas.DataFrame
        A validated, normalised copy. The input is never modified.

    Raises
    ------
    ELTValidationError
        If any check fails. The message lists every failure, not just the first.

    Examples

    >>> import pandas as pd
    >>> from catagg import validate_elt
    >>> elt = pd.DataFrame(
    ...     {

        raise ELTValidationError(f"ELT must be a pandas DataFrame, got {type(elt).__name__}.")

    missing = [column for column in ELT_COLUMNS if column not in elt.columns]
    if missing:
        raise ELTValidationError(
            f"ELT is missing required column(s): {', '.join(missing)}. "
            f"Required schema is {', '.join(ELT_COLUMNS)}."
        )

    frame = elt.copy()
    problems: list[str] = []

    for column, dtype in ELT_DTYPES.items():
        try:
            frame[column] = frame[column].astype(pandas_dtype(dtype))
        except (TypeError, ValueError) as error:
            problems.append(f"column {column!r} cannot be cast to {dtype}: {error}")

    if problems:
        raise ELTValidationError("ELT failed validation:\n  - " + "\n  - ".join(problems))

    extra = [column for column in frame.columns if column not in ELT_COLUMNS]
    frame = frame[[*ELT_COLUMNS, *extra]].reset_index(drop=True)

    event_id = frame["event_id"]
    if event_id.isna().any():
        problems.append("event_id contains nulls")
    duplicated = event_id.duplicated(keep=False).to_numpy(dtype=bool)
    if bool(duplicated.any()):
        problems.append(f"event_id must be unique; duplicated: {_report(event_id, duplicated)}")

    for column in ("rate", "exposure_value"):
        values = frame[column].to_numpy(dtype=np.float64)
        bad = ~np.isfinite(values) | (values <= 0.0)
        if bool(bad.any()):
            problems.append(
                f"{column} must be finite and strictly positive: {_report(event_id, bad)}"
            )

    for column in ("mean_loss", "std_loss"):
        values = frame[column].to_numpy(dtype=np.float64)
        bad = ~np.isfinite(values) | (values < 0.0)
        if bool(bad.any()):
            problems.append(f"{column} must be finite and non-negative: {_report(event_id, bad)}")

    if not problems:
        mean = frame["mean_loss"].to_numpy()
        std = frame["std_loss"].to_numpy()
        exposure = frame["exposure_value"].to_numpy()

        over_exposed = mean > exposure
        if bool(over_exposed.any()):
            problems.append(
                f"mean_loss must not exceed exposure_value: {_report(event_id, over_exposed)}"
            )

        bound = mean * (exposure - mean)
        infeasible = (std**2 > bound * (1.0 + _VARIANCE_RTOL)) & ~over_exposed
        if bool(infeasible.any()):
            problems.append(
                "std_loss exceeds the largest standard deviation a distribution on "
                "[0, exposure_value] with this mean can have, "
                "sqrt(mean_loss * (exposure_value - mean_loss)): "
                f"{_report(event_id, infeasible)}"
            )

    for column in ("peril", "region"):
        labels = frame[column]
        bad = (labels.isna() | (labels.fillna("").str.strip() == "")).to_numpy(dtype=bool)
        if bool(bad.any()):
            problems.append(f"{column} must be a non-empty label: {_report(event_id, bad)}")

    if problems:
        raise ELTValidationError("ELT failed validation:\n  - " + "\n  - ".join(problems))

    return frame

    which is what the engine currently does.

        Event loss table.

        Frequency model, as passed to `catagg.simulate`.

        Negative binomial shape parameter ``k``, if applicable.

        Column defining the frequency groups, matching the simulation.

        Include the ``sum(rate * std_loss ** 2)`` severity term. Leave ``False``

    ------

    coefficient = model.excess_variance_coefficient

    elif group_by in elt.columns:
        labels = elt[group_by]
    else:

    rate = elt["rate"].to_numpy(dtype=np.float64)
    mean = elt["mean_loss"].to_numpy(dtype=np.float64)
    std = elt["std_loss"].to_numpy(dtype=np.float64)

        mask = (labels == label).to_numpy()
        variance += coefficient * float(np.dot(rate[mask], mean[mask])) ** 2
    return variance

    def to_ylt(
    yelt: pd.DataFrame, n_years: int | None = None, *, column: str = "gross_loss"
) -> pd.DataFrame:
    """Collapse a YELT to one row per simulated year.

    Every year in ``range(n_years)`` appears, including the ones in which nothing
    happened. Those years carry zero loss and are not optional: dropping them, as
    a bare ``groupby("sim_year")`` silently does, divides by the number of
    *non-empty* years and inflates the AAL, by a factor of roughly
    ``1 / (1 - exp(-Lambda))`` for a Poisson portfolio.

    Parameters
    ----------
    yelt
        Year event loss table.
    n_years
        Explicit year count if ``yelt.attrs`` no longer carries it.
    column
        The per-occurrence loss column to collapse. ``"gross_loss"`` for a YELT
        from `simulate`; ``"ceded_loss"`` or ``"net_loss"`` for the table a
        reinsurance programme returns.

    Returns
    -------
    pandas.DataFrame
        A YLT with columns ``sim_year``, ``aggregate_loss`` and
        ``max_occurrence_loss``.

    Raises
    ------
    CataggError
        If ``column`` is not in the table.
    """
    if column not in yelt.columns:
        raise CataggError(
            f"column {column!r} is not in the table; got columns {list(yelt.columns)}."
        )
    resolved = n_years_of(yelt, n_years)
    years = np.arange(resolved, dtype=np.int32)
    sim_year = yelt["sim_year"].to_numpy(dtype=np.int64)
    loss = yelt[column].to_numpy(dtype=np.float64)

    aggregate = np.bincount(sim_year, weights=loss, minlength=resolved)
    maximum = np.zeros(resolved, dtype=np.float64)
    np.maximum.at(maximum, sim_year, loss)

    ylt = pd.DataFrame(
        {"sim_year": years, "aggregate_loss": aggregate, "max_occurrence_loss": maximum}
    )
    ylt.attrs["n_years"] = resolved
    return ylt
