    Metrics¶

    v0.1.0 is in development

    This page documents the gross view: EP curves, tail metrics and their Monte Carlo error. For ceded and net curves, pass the result of a reinsurance programme with column="ceded_loss" or column="net_loss"; see Financial structures.

    An exceedance probability curve is the empirical distribution of a per-year loss, read from the tail. Two of them matter, and they answer different questions.

    OEP, occurrence exceedance probability, is the distribution of the largest single event in a year. It is what a per-occurrence layer responds to. AEP, aggregate exceedance probability, is the distribution of total annual loss. It is what aggregate cover and capital respond to. Both come from the same year loss table, so one simulation gives you both.

    import catagg as ca

elt = ca.swiss_multiperil_elt(n_events=400, seed=0)
yelt = ca.simulate(elt, n_years=50_000, seed=1, secondary_uncertainty=True)

aggregate = ca.ep_curve(yelt, kind="AEP")
print(aggregate.at_return_period([100, 200, 250]))
print(aggregate.tvar(200))

    EPCurve keeps the whole per-year loss vector rather than a summarised curve, so any return period, tail metric or standard error can be read afterwards without re-simulating.

    Return periods, and which plotting position¶

    A return period \(R\) is the reciprocal of an annual exceedance probability, so the loss at \(R\) is the \(1 - 1/R\) quantile of the annual loss. The quantile uses the Weibull plotting position, \(k / (n + 1)\) for the \(k\)-th largest of \(n\) simulated years.

    That is not a cosmetic choice. For a continuous distribution \(k / (n + 1)\) is unbiased for the exceedance probability of the \(k\)-th order statistic. The \(k / n\) convention some vendor tools use is biased, and it cannot represent the largest simulated year at all without assigning it a zero exceedance probability — an infinite return period from one observation.

    Refusing to extrapolate¶

    at_return_period raises rather than answering when the return period is longer than the simulation:

    >>> curve = ca.ep_curve(ca.simulate(elt, n_years=10_000, seed=1), kind="AEP")
>>> curve.at_return_period(10_000)
CataggError: return_period 10000 exceeds the 10000 simulated years...

    Reading a 1-in-10,000 loss off 10,000 simulated years returns the single largest year and dresses one observation up as a return period. The library will not do it quietly.

    TVaR¶

    Tail value at risk is the mean loss in the years that exceed a return period, so it answers what capital regimes actually ask: not "how bad is the 1-in-200 year" but "how bad is the average year worse than that". It is computed as the integrated expected shortfall over the largest \(n / R\) years, with a fractional weight on the boundary year so the figure stays continuous in \(R\) rather than jumping as the count crosses an integer.

    Standard error is not optional¶

    Every figure this module returns carries the Monte Carlo standard error of the estimate, because a return period read off a simulation is a statistic and carries sampling error like any other. For the example portfolio the RP-200 AEP estimated from 10,000 simulation years has a standard error of around 8% — large enough to move a reinsurance decision, and almost never reported.

    Neither estimator introduces a tuning constant, and both are checked against a replication study rather than asserted.

    Quantiles¶

    The empirical CDF at the quantile has standard deviation \(\sqrt{p(1-p)/n}\). Perturbing the probability level by exactly that amount and reading the quantile function at both ends gives the sampling spread of the estimate, mapped through the distribution's own shape:

    \[\text{se} = \frac{Q(u + h) - Q(u - h)}{2}, \qquad u = 1 - p, \quad h = \sqrt{\frac{p\,(1-p)}{n}}\]

    This is the Siddiqui density-quantile estimator with the bandwidth pinned to the statistically natural scale rather than chosen. It needs no density estimate and degrades correctly in the far tail, where the spacing between order statistics is wide.

    TVaR, and the mistake worth naming¶

    The tail mean over \(k = np\) years is a mean, so the obvious estimator of its error is \(s_{\text{tail}} / \sqrt{k}\).

    That estimator is wrong, and wrong in the dangerous direction. It treats the exceedance threshold as known when the threshold is itself estimated from the same sample. Against a replication study it understates the true error by between a fifth and a third. The correction restores what it omits:

    \[\text{se} = \sqrt{\frac{s_{\text{tail}}^2 + (1 - p)\,(\text{TVaR} - \text{VaR})^2}{k}}\]

    How well they do¶

    Measured against 30 independent reruns of the same portfolio, as the ratio of the error a single run reports to the spread actually observed across runs:

    Simulated years Quantile TVaR
    10,000 1.14 1.15
    100,000 0.98 0.99

    Both run slightly conservative at short simulations, which is the right direction for a number whose purpose is to stop someone over-reading a tail. The tests assert this ratio directly, so a change that quietly breaks an error estimate fails rather than shipping a comfortable, wrong number.

    Plotting¶

    matplotlib is not a runtime dependency. The engine needs numpy, pandas, pyarrow and scipy, and a library that forces a plotting stack on everyone who imports it has made a decision on their behalf. Install the extra:

    pip install catagg[plot]

    from catagg.plot import ep_comparison

ep_comparison({"Gross": aggregate}, title="Swiss multi-peril, gross")

    The shaded band is plus or minus one standard error, drawn by default. At the long return periods on the right of the plot it is wide enough to change a decision, and a curve drawn as a clean line hides that.

    catagg.metrics.ep ¶

    Exceedance probability curves, tail metrics, and their Monte Carlo error.

    An EP curve is the empirical distribution of a per-year loss, read from the tail. Two of them matter, and they answer different questions:

    • OEP, occurrence exceedance probability, is the distribution of the largest single event in a year. It is what a per-occurrence layer responds to.
    • AEP, aggregate exceedance probability, is the distribution of the total annual loss. It is what aggregate cover and capital respond to.

    Both come from the year loss table, so both are available from one simulation.

    Return periods

    A return period R is the reciprocal of an annual exceedance probability: R = 200 means P(loss > x) = 1 / 200. The loss at that return period is therefore the 1 - 1 / R quantile of the annual loss.

    The quantile uses the Weibull plotting position, k / (n + 1) for the k-th largest of n years. That choice is not cosmetic: for a continuous distribution k / (n + 1) is unbiased for the exceedance probability of the k-th order statistic, whereas the k / n convention some vendor tools use is biased and cannot represent the largest year at all without assigning it a zero exceedance probability. numpy names the convention explicitly, so method="weibull" in the code below is the whole of the definition.

    Standard error is not optional

    Every figure this module returns comes with the Monte Carlo standard error of the estimate, because a return period read off a simulation is a statistic and carries sampling error like any other. For a realistic portfolio the RP-200 AEP estimated from 10,000 simulation years has a standard error of several percent -- large enough to move a reinsurance decision, and almost never reported.

    Two estimators are used, and neither introduces a tuning constant.

    Quantiles. The empirical CDF at the quantile has standard deviation sqrt(p * (1 - p) / n). Perturbing the probability level by exactly that amount and reading the quantile function at both ends gives the sampling spread of the estimate, mapped through the distribution's own shape::

    se = (Q(u + h) - Q(u - h)) / 2,    u = 1 - p,  h = sqrt(p * (1 - p) / n)

    This is the Siddiqui density-quantile estimator with the bandwidth pinned to the statistically natural scale rather than chosen. It needs no density estimate, degrades correctly in the far tail where the spacing between order statistics is wide, and against a 60-run replication study it lands within 15% of the true sampling standard deviation at 10,000 years and within 2% at 100,000.

    TVaR. The tail mean over k = n * p years is a mean, so an obvious estimator of its error is s_tail / sqrt(k). That estimator is wrong, and wrong in the dangerous direction: it treats the exceedance threshold as known when the threshold is itself estimated from the same sample. Against the same replication study it understates the true error by between a fifth and a third. The term (1 - p) * (TVaR - VaR) ** 2 restores what it omits::

    se = sqrt((s_tail**2 + (1 - p) * (tvar - var) ** 2) / k)

    which lands within 15% at 10,000 years and within 1% at 100,000.

    Both estimators run slightly conservative at short simulations, which is the right direction for a number whose purpose is to stop someone over-reading a tail.

    @dataclass(frozen=True, eq=False)
class EPCurve:
    """An exceedance probability curve, held as the full simulated distribution.

    Build one with `ep_curve`. The whole per-year loss vector is kept rather
    than a summarised curve, so any return period, tail metric or standard
    error can be read afterwards without re-simulating.

    Attributes
    ----------
    losses
        Per-year loss, sorted ascending, one entry per simulated year including
        years with no events.
    kind
        ``"OEP"`` or ``"AEP"``.
    """

    losses: NDArray[np.float64]
    kind: EPKind

    def __len__(self) -> int:
        """Return the number of simulated years."""
        return int(self.losses.shape[0])

    @property
    def n_years(self) -> int:
        """Number of simulated years behind the curve."""
        return len(self)

    @property
    def mean(self) -> float:
        """Mean per-year loss. For an AEP curve this is the AAL."""
        return float(self.losses.mean())

    @property
    def mean_standard_error(self) -> float:
        """Monte Carlo standard error of `mean`.

        An ordinary standard error of a mean. `catagg.aal_standard_error`
        computes the same quantity in closed form from the ELT, without
        simulating; agreement between the two is a check on both.
        """
        return float(self.losses.std(ddof=1) / np.sqrt(self.n_years))

    def _check_return_periods(self, values: NDArray[np.float64]) -> None:
        """Reject return periods the simulation cannot support.

        Raises
        ------
        CataggError
            If any return period is at or below one, or longer than the
            simulation itself. The upper bound is deliberate: reading a
            10,000-year loss off 10,000 simulated years returns the single
            largest year and dresses one observation up as a return period.
        """
        if np.any(values <= 1.0):
            raise CataggError("return_period must be greater than 1.")
        if np.any(values > self.n_years):
            longest = float(values.max())
            raise CataggError(
                f"return_period {longest:g} exceeds the {self.n_years} simulated years. "
                f"Estimating it needs at least {int(np.ceil(longest))} years; beyond that "
                "the estimate is the largest simulated year, not a return period."
            )

    def _quantile(self, probability: NDArray[np.float64]) -> NDArray[np.float64]:
        """Empirical quantile at the Weibull plotting position."""
        clipped = np.clip(probability, 0.0, 1.0)
        return np.asarray(np.quantile(self.losses, clipped, method="weibull"), dtype=np.float64)

    def at_return_period(
        self, return_period: ReturnPeriods = STANDARD_RETURN_PERIODS
    ) -> pd.DataFrame:
        """Return the loss at one or more return periods, with its standard error.

        Parameters
        ----------
        return_period
            Return period in years, scalar or sequence. Defaults to
            `STANDARD_RETURN_PERIODS`.

        Returns
        -------
        pandas.DataFrame
            Columns ``return_period``, ``exceedance_probability``, ``loss`` and
            ``se``, one row per requested return period.

        Raises
        ------
        CataggError
            If a return period is at or below one, or exceeds the number of
            simulated years.

        Examples
        --------
        >>> import catagg as ca
        >>> elt = ca.swiss_multiperil_elt(n_events=200, seed=0)
        >>> yelt = ca.simulate(elt, n_years=20_000, seed=1)
        >>> curve = ca.ep_curve(yelt, kind="AEP")
        >>> list(curve.at_return_period([100, 200]).columns)
        ['return_period', 'exceedance_probability', 'loss', 'se']
        """
        values = _as_return_periods(return_period)
        self._check_return_periods(values)

        probability = 1.0 / values
        level = 1.0 - probability
        bandwidth = np.sqrt(probability * (1.0 - probability) / self.n_years)
        spread = self._quantile(level + bandwidth) - self._quantile(level - bandwidth)

        return pd.DataFrame(
            {
                "return_period": values,
                "exceedance_probability": probability,
                "loss": self._quantile(level),
                "se": spread / 2.0,
            }
        )

    def tvar(self, return_period: ReturnPeriods = STANDARD_RETURN_PERIODS) -> pd.DataFrame:
        """Return the tail value at risk at one or more return periods.

        TVaR is the mean loss in the years that exceed the return period, so it
        answers what capital regimes actually ask: not "how bad is the 1-in-200
        year" but "how bad is the average year worse than that". It is computed
        as the integrated expected shortfall over the largest ``n / R`` years,
        with a fractional weight on the boundary year so the figure stays
        continuous in the return period.

        Parameters
        ----------
        return_period
            Return period in years, scalar or sequence. Defaults to
            `STANDARD_RETURN_PERIODS`.

        Returns
        -------
        pandas.DataFrame
            Columns ``return_period``, ``exceedance_probability``, ``tvar`` and
            ``se``. The standard error is ``NaN`` where fewer than two
            simulated years exceed the return period.

        Raises
        ------
        CataggError
            If a return period is at or below one, or exceeds the number of
            simulated years.
        """
        values = _as_return_periods(return_period)
        self._check_return_periods(values)

        probability = 1.0 / values
        descending = self.losses[::-1]
        var = self._quantile(1.0 - probability)

        exceeding = probability * self.n_years
        whole = np.floor(exceeding).astype(np.int64)
        cumulative = np.concatenate(([0.0], np.cumsum(descending)))

        # The whole years above the threshold, plus the fraction of the next one
        # that the return period reaches into.
        boundary = descending[np.minimum(whole, self.n_years - 1)]
        total = cumulative[whole] + (exceeding - whole) * boundary
        tail_mean = total / exceeding

        standard_error = np.full(values.shape, np.nan, dtype=np.float64)
        for index, count in enumerate(whole):
            if count < 2:
                continue
            tail = descending[:count]
            tail_variance = float(tail.var(ddof=1))
            threshold_term = (1.0 - probability[index]) * (tail_mean[index] - var[index]) ** 2
            standard_error[index] = np.sqrt((tail_variance + threshold_term) / exceeding[index])

        return pd.DataFrame(
            {
                "return_period": values,
                "exceedance_probability": probability,
                "tvar": tail_mean,
                "se": standard_error,
            }
        )

    def to_frame(self) -> pd.DataFrame:
        """Return the whole curve, one row per simulated year.

        Returns
        -------
        pandas.DataFrame
            Columns ``rank`` (1 for the largest year), ``exceedance_probability``
            at the Weibull plotting position, ``return_period`` and ``loss``,
            ordered from the largest loss down.
        """
        rank = np.arange(1, self.n_years + 1, dtype=np.int64)
        probability = rank / (self.n_years + 1)
        return pd.DataFrame(
            {
                "rank": rank,
                "exceedance_probability": probability,
                "return_period": 1.0 / probability,
                "loss": self.losses[::-1],
            }
        )

    def to_frame(self) -> pd.DataFrame:
    """Return the whole curve, one row per simulated year.

    Returns
    -------
    pandas.DataFrame
        Columns ``rank`` (1 for the largest year), ``exceedance_probability``
        at the Weibull plotting position, ``return_period`` and ``loss``,
        ordered from the largest loss down.
    """
    rank = np.arange(1, self.n_years + 1, dtype=np.int64)
    probability = rank / (self.n_years + 1)
    return pd.DataFrame(
        {
            "rank": rank,
            "exceedance_probability": probability,
            "return_period": 1.0 / probability,
            "loss": self.losses[::-1],
        }
    )

    def ep_curve(losses: pd.DataFrame, kind: EPKind = "OEP", *, column: str | None = None) -> EPCurve:
    """Build an exceedance probability curve from a YELT or a YLT.

    Parameters
    ----------
    losses
        A year event loss table as returned by `catagg.simulate`, or a year
        loss table as returned by `catagg.to_ylt`. A YELT is collapsed first.
    kind
        ``"OEP"`` for the annual maximum occurrence, ``"AEP"`` for the annual
        aggregate.
    column
        For a YELT, the per-occurrence loss column to use: ``"gross_loss"``
        (the default), or ``"ceded_loss"`` or ``"net_loss"`` from a reinsurance
        programme's result. Not accepted with a YLT, which has already
        collapsed its occurrences.

    Returns
    -------
    EPCurve
        The curve, holding one loss per simulated year.

    Raises
    ------
    CataggError
        If ``kind`` is not ``"OEP"`` or ``"AEP"``, the frame is neither a YELT
        nor a YLT, ``column`` is missing from it, or ``column`` is given with a
        YLT.

    Examples
    --------
    >>> import catagg as ca
    >>> elt = ca.swiss_multiperil_elt(n_events=200, seed=0)
    >>> yelt = ca.simulate(elt, n_years=10_000, seed=1)
    >>> ca.ep_curve(yelt, kind="AEP").n_years
    10000
    """
    from catagg.simulate.engine import to_ylt

    if kind not in _SOURCE_COLUMN:
        raise CataggError(f"kind must be 'OEP' or 'AEP', got {kind!r}.")

    source = _SOURCE_COLUMN[kind]
    if source in losses.columns:
        if column is not None:
            raise CataggError(
                f"column={column!r} applies to a YELT, but this is a YLT: its "
                "occurrences are already collapsed."
            )
        ylt = losses
    elif column is not None:
        ylt = to_ylt(losses, column=column)
    elif "gross_loss" in losses.columns:
        ylt = to_ylt(losses)
    else:
        raise CataggError(
            "losses must be a YELT (with a gross_loss column) or a YLT (with "
            f"a {source} column); got columns {list(losses.columns)}."
        )

    return EPCurve(losses=np.sort(ylt[source].to_numpy(dtype=np.float64)), kind=kind)

    def ep_comparison(
    curves: Mapping[str, EPCurve],
    *,
    return_periods: np.ndarray | None = None,
    show_standard_error: bool = True,
    ax: Axes | None = None,
    title: str | None = None,
) -> Axes:
    """Plot one or more exceedance probability curves against return period.

    The shaded band is plus or minus one Monte Carlo standard error. It is drawn
    by default because it is the part reviewers have never seen: at the long
    return periods on the right of the plot the band is wide enough to change a
    decision, and a curve drawn as a clean line hides that.

    Parameters
    ----------
    curves
        Mapping of label to `catagg.EPCurve`. All curves must be the same kind,
        since an OEP and an AEP curve do not share a vertical axis.
    return_periods
        Return periods to evaluate. Defaults to a log-spaced grid running from
        two years to the length of the shortest simulation.
    show_standard_error
        Draw the standard error band.
    ax
        Existing axes to draw on. A new figure is created when omitted.
    title
        Axes title.

    Returns
    -------
    matplotlib.axes.Axes
        The axes drawn on.

    Raises
    ------
    CataggError
        If ``curves`` is empty, mixes OEP and AEP, or matplotlib is not
        installed.
    """
    if not curves:
        raise CataggError("ep_comparison needs at least one curve.")

    kinds = {curve.kind for curve in curves.values()}
    if len(kinds) > 1:
        raise CataggError(
            f"All curves must be the same kind; got {sorted(kinds)}. Plot OEP and "
            "AEP on separate axes."
        )
    kind = kinds.pop()

    plt = _require_pyplot()
    if ax is None:
        _, ax = plt.subplots(figsize=(7.0, 4.5))

    if return_periods is None:
        return_periods = _default_return_periods(min(c.n_years for c in curves.values()))

    for label, curve in curves.items():
        table = curve.at_return_period(return_periods)
        loss = table["loss"].to_numpy() / 1e6
        (line,) = ax.plot(table["return_period"], loss, label=label, linewidth=1.8)
        if show_standard_error:
            error = table["se"].to_numpy() / 1e6
            ax.fill_between(
                table["return_period"],
                loss - error,
                loss + error,
                color=line.get_color(),
                alpha=0.20,
                linewidth=0,
            )

    ax.set_xscale("log")
    ax.set_xlabel("Return period (years)")
    ax.set_ylabel(f"{kind} loss (millions)")
    ax.grid(visible=True, which="both", alpha=0.25, linewidth=0.6)
    ax.margins(x=0)
    if len(curves) > 1:
        ax.legend(frameon=False)
    if title:
        ax.set_title(title)
    return ax
